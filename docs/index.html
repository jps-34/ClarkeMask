ClarkeMask

PixInsight update repository for the ClarkeMask script: masks geostationary satellite trails in each registered light frame, so that integration rejects them pixel by pixel. Runs inside WBPP as an event script, or from its own dialog.

In PixInsight, open Resources > Updates > Manage Repositories and add:

https://jps-34.github.io/ClarkeMask/
